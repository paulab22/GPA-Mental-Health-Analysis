## About This Project

This project analyzes the relationship between students’ GPA and self-reported mental health indicators, focusing on depression and anxiety. Using a Student Mental Health dataset, the analysis uses data cleaning, descriptive statistics, frequency tables, and bar plots to examine how reports of depression and anxiety vary across different GPA ranges. The project explores patterns between academic performance and mental health among college students.
